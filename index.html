How it is calculated

Level cost per planet M/C/D = 84/42/14 × 1.4^(L−1) Each resource is rounded to the nearest whole unit.
Lithium/hour per planet floor(220 × L × 1.1^(L−1)) Matches observed in-game IAS values, including levels 20–34.
Default MSU (3:2:1) MSU = Metal + 1.5 × Crystal + 3 × Deuterium You can change the trade ratio above.

“Output gain” refers to IAS lithium conversion output. If Orion reward scaling is confirmed to be directly proportional to this value, the same percentage can be used as the relative reward gain.
